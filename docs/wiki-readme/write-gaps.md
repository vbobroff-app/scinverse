# Разрывы записи (Write Gaps)

Пользовательское описание: когда на ганте записи нужен красный слой и что он значит.
Слои системы — [layers.md](layers.md) · инциденты — [incident.md](incident.md).

---

## 1. Зачем это нужно

Когда инструмент **стоит на запись**, сделки должны попадать в историю. Иногда на ганте
видно «дыру» — участок, где данных нет. Важно не путать две разные ситуации:

| Что видно | Что это значит | Нужно ли восстанавливать? |
|-----------|----------------|---------------------------|
| Запись включена, связь жива, сделок нет | **Тихий рынок** — система работала, рынок молчал | Нет |
| Запись включена, но в это время была поломка (обрыв / краш / тихий обрыв) | **Разрыв записи** — данные должны были писаться, но не писались | **Да** |

**Разрыв записи (Write Gap)** — второй случай: интервал «надо восстановить», без разбора
причины поломки. Причина (обрыв связи / падение сервера / тихий обрыв) остаётся в
[журнале инцидентов](incident.md) и на [ленте соединения](layers.md); для восстановления
важен **факт и границы дыры**.

---

## 2. Когда запись «должна вестись»

**Намерение** — запись по инструменту включена (вручную или автозапись). Пока намерение есть,
система обязана принимать сделки.

Намерение — это не «авто по расписанию соединения». Расписание связи только поднимает или
опускает линк; намерение появляется, когда реально стартовала запись инструмента.

---

## 3. Картина на ганте записи

Слои дорожки инструмента (снизу вверх по смыслу):

1. **Намерение** — «стояло на запись».
2. **Живость** — «захват / связь в этот момент живы».
3. **Подложка** — пересечение намерения и живости (честный фон).
4. **Сделки** — яркие ячейки: реально была торговля.
5. **Разрыв записи** (по галке) — сплошной **красный**: здесь нужна дозагрузка.

Красный слой — **одного цвета**, без жёлтого и без маркеров «чья вина». Либо дыра для
восстановления, либо нет. Ячейки сделок остаются яркими поверх подложки.

Лента **соединения** (выше списка инструментов) по-прежнему показывает детали инцидентов
(обрыв / падение сервера, кто восстанавливает). Это другой слой — про связь, не про
«что бэкапить». См. [layers.md](layers.md).

---

## 4. Как получается красный интервал

Два шага.

### Дыра по сделкам (Write Hole)

Есть намерение, и в этот период был (или ещё открыт) **инцидент**, пересекающийся с тишиной
сделок. Границы дыры — **не** по моменту детекта инцидента, а по сделкам:

- **влево** — последняя сделка до дыры;
- **вправо** — первая сделка после (или «сейчас», если инцидент ещё открыт).

Так границы самые точные: сделки пропадают раньше, чем система успевает открыть инцидент, и
возвращаются позже, чем связь формально восстановилась.

```text
|------ дыра по сделкам ------|
   |------ инцидент (детект) ------|
```

Тихий обрыв (нет сделок, проверка связи не проходит) тоже открывает инцидент — тот же путь.

Тихий рынок: намерение есть, сделок нет, **инцидента нет** → дыры по сделкам нет → красного нет.

### Разрыв записи (Write Gap)

```text
разрыв записи = дыра по сделкам ∩ рабочее окно расписания
```

Вне торгового / рабочего окна красного нет: восстанавливать нечего. Расписание **нарезает** дыру,
а не решает, был ли сбой. Подробнее про роль расписания — [incident.md](incident.md) §5.

Несколько инцидентов в одной тишине не важны: достаточно факта пересечения; края всё равно по
сделкам.

---

## 5. Зачем оператору

- На ганте сразу видно **где чинить историю**, а не только «где мигала связь».
- Интервалы разрыва записи — параметры для будущего **восстановления сделок** (что дозагрузить).
- Галка слоя: можно смотреть подложку и сделки без красного или включить разрывы записи.

---

## 6. Коротко

| Термин | Смысл |
|--------|--------|
| Намерение | Запись должна вестись |
| Тихий рынок | Нет сделок при живой системе — норма |
| Инцидент | Зафиксированная поломка (связь / сервер / тихий обрыв) |
| Дыра по сделкам | Тишина сделок при намерении ∩ инцидент, края по последней и первой сделке |
| Разрыв записи | Дыра по сделкам внутри рабочего окна — кандидат на восстановление |

Красный на ганте записи = **разрыв записи**. Причину поломки смотрите в журнале и на ленте соединения.
